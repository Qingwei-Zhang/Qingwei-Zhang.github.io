SELECTED WORK

Research & Projects

LLM Systems

KV Cache Remaining Lifetime Prediction

Predicting the remaining lifetime and future reuse of KV-cache chunks to support more efficient memory hierarchy and cache scheduling for large language model inference.

Multimodal Agent

Preference-Aware Proactive In-Vehicle Agent

A structured-memory framework for proactive spatial interaction in multi-user, multimodal in-vehicle scenarios, covering eventized memory, trigger-strength labeling, retrieval, and proactive response.

Computer Vision

Unsupervised Wind Turbine Blade Defect Detection

Unsupervised anomaly detection for wind-turbine blade inspection using DINOv2 features, with emphasis on robust defect localization and evaluation under imbalanced industrial data.

Human-Centered AI

Hand Pose Estimation from Sparse Sensing

Exploring learning-based approaches for recovering expressive hand poses from sparse sensing signals, with an emphasis on compact representations and practical interaction scenarios.
